# VoiceSushiOrderG510

横スクロール式メニュー、音声注文、日本語音声ガイドを備えたAndroidセルフオーダーのデモです。

## 主な機能
- 横スワイプ／自動スクロールの商品レーン
- 商品カードのタッチ注文
- Android標準音声認識による「まぐろを2皿」などの注文
- TextToSpeechによる日本語接客ガイド
- 注文かご、合計、全取消、注文確定
- ランドスケープ固定、G510系の大型ディスプレイ向けUI

## ビルド
1. Android Studioでこのフォルダーを開く
2. Gradle Sync
3. G510端末をUSB接続し、Run
4. 初回起動時にマイク権限を許可

## 音声例
- 「まぐろを2皿」
- 「サーモン」
- 「味噌汁を1つ」
- 「お会計」
- 「全部消して」

## 注意
この版はPoCです。音声認識はAndroid端末のRecognizerIntent実装に依存します。店舗運用では、商品DB、POS/KDS API、売切れ管理、アレルゲン、多言語、店員呼出、ネットワーク再送、端末監視を追加してください。
