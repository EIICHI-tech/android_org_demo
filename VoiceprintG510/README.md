# VoiceprintG510

G510向けAndroid声紋認識PoCです。Android Studioでフォルダーを開き、Gradle同期後に `app` を実行してください。

## 操作
1. マイク権限を許可
2. 「声を登録」を3回実行。毎回4秒間、同じ距離と自然な声量で話す
3. 「本人確認」で4秒間話す
4. 一致度86%以上を本人として表示

## 実装
- 16 kHz / mono / PCM16
- VOICE_RECOGNITION音源
- RMS、ゼロ交差率、32帯域Goertzel対数エネルギー
- L2正規化ベクトルとコサイン類似度
- 登録テンプレートはActivity専用SharedPreferencesに保存
- 外部通信、クラウド、追加ライブラリなし

## 重要
これは展示・技術検証用PoCです。録音再生・合成音声への生体検知、暗号化鍵管理、改ざん耐性、端末間校正、FAR/FRR評価は含みません。重要な本人認証はPIN/FIDO2等と組み合わせてください。閾値86%は初期値であり、実環境の本人・他人データで調整が必要です。
