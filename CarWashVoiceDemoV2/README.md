# 洗車音声操作デモ V2

画像の洗車券売機を参考に、コースを一覧表示するメニューへ変更したAndroidデモです。

## 主な変更
- 「Hi GEMINI」「ハイ ジェミニ」「はい、ジェミニ」で音声操作を開始
- ティアラコート、シルキーコート、ワックス、ディーラーコート車対応洗車、シャンプーを一覧表示
- 各コースの通常版と洗浄工程追加版を表示
- タイヤ洗浄 +300円
- 音声またはタッチで選択
- 「大型へ変更」「タイヤ洗浄」「決定」「キャンセル」に対応

## 音声操作例
1. Hi GEMINI
2. ティアラコート
3. タイヤ洗浄
4. 決定

## 重要
Android標準SpeechRecognizerを連続再起動してウェイクワード風に動作させるデモ実装です。DSP常時待受型の正式なホットワードエンジンではありません。端末の音声認識サービスによってはネット接続が必要です。製品化時はPicovoice Porcupine、Vosk、または専用DSP/KWSモデル等への置換を推奨します。
