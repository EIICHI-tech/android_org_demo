# Emergency Sound Alert Demo

G510 / Android 14向けの縦画面デモです。マイク入力を解析し、周期的に周波数が変化する大きな音をサイレン候補として画面とTTSで警告します。

## Build
1. Android Studioでフォルダーを開く
2. Gradle Sync
3. G510をUSB接続しRun
4. 初回起動時にマイク権限を許可

## 注意
これは展示用のルールベース判定です。救急車、パトカー、自治体防災放送を高精度に分類するには、対象地域・実機マイクで収録したデータとTFLite音響分類モデルへ置換してください。誤検知・見逃しがあり得るため、人命・避難判断には使用しないでください。
