# Hospital Voice Reception

G510 Android 14向け、縦型の病院音声受付デモです。

## 機能
- Jetpack Composeによる縦型受付UI
- Compose Canvas製の受付アバター
- Android SpeechRecognizerによる日本語音声認識
- TextToSpeechによる回答読み上げ
- 初診・再診・診療科受付
- 院内案内、受付時間、薬受渡案内
- 緊急キーワード検出
- タッチ操作フォールバック

## 開き方
1. Android Studioでこのフォルダーを開く
2. Gradle Syncを実行
3. G510をADB接続
4. appを実行

## 注意
- 初回起動時にマイク権限を許可してください。
- SpeechRecognizerは端末にインストールされた音声認識サービスを利用します。
- 診療時間、受付番号、院内位置はデモデータです。
- 医療診断や薬の判断を行うアプリではありません。

## 完全ハンズフリー版
- 起動すると自動的にウェイクワード待機を開始します。
- 「HI びょういん / HI 病院 / ハイ病院 / はい病院」を検出すると「はい、お伺いします」と応答し、その後の1発話を受付コマンドとして認識します。
- 応答読み上げ終了後は自動的にウェイクワード待機へ戻ります。
- マイクボタンは障害時のフォールバックとして残していますが、通常操作には不要です。
- Androidの仕様上、新規インストール直後だけはRECORD_AUDIOのシステム権限ダイアログで利用者の許可が必要です。許可後はアプリ内ボタン操作不要です。
