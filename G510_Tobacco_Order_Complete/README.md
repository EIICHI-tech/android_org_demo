# G510 Tobacco Order Demo

Android / Genio G510向けのセルフオーダーデモです。

## 機能
- 日本語音声認識で銘柄検索
- 商品番号とAI生成の高品質な架空パッケージ画像表示
- 画面タップによる商品選択
- CameraX + ML Kitによる顔の存在検出
- スタッフ確認による20歳以上確認フロー

## 重要
- 本アプリは顔画像から年齢を自動判定しません。見た目年齢は誤差とバイアスが大きいため、販売可否をAIだけで決めない設計です。
- 商品画像は実商品写真ではなく、デモ用に作成した簡易パッケージ画像です。実店舗展示時は権利処理済みの商品画像へ差し替えてください。
- 銘柄、番号、在庫、価格は `app/src/main/assets/catalog.json` で管理します。

## ビルド
1. Android Studio Ladybug以降でフォルダを開く
2. JDK 17を選択
3. Gradle Sync
4. G510 Android 14端末をUSB接続
5. Run または `./gradlew assembleDebug`

## 実商品画像への差し替え
AI生成画像は `app/src/main/res/drawable/pack_001.webp` から `pack_012.webp` に同梱済みです。catalog.json側のdrawable名は変更不要です。

## 運用上の注意
日本国内でのたばこ販売では20歳未満への販売防止が必要です。展示・実証では、スタッフ確認、証明書確認、販売POS側の最終承認を残してください。

## Hi Tabako ウェイクワード
アプリ起動後、マイク権限を許可すると自動的に待機します。

1. 「Hi Tabako」と話す
2. 確認音の後に銘柄名を話す
3. 商品と店員向け番号を表示
4. 自動的に「Hi Tabako」待機へ戻る

認識揺れに備え、「ハイタバコ」「ヘイタバコ」「hai tabako」もウェイクワードとして受け付けます。Android標準の `SpeechRecognizer` を使用するため、端末に設定された音声認識サービスによってはネットワーク接続が必要です。

## 提供画像版の商品番号
001 ラッキーストライク / 002 キャメル / 003 ネオ / 004 クール / 005 ミックス / 006 センティア / 007 ヒーツ / 008 ケント / 009 メビウス プルームエックス / 010 メビウス プルームテックプラス / 011 テリア / 012 マールボロ IQOS

このチャットのアップロード作業領域では、同一ファイル名 `image.png` の複数添付が最後の1枚で上書きされ、実ファイルとして取得できたのはマールボロ画像1枚のみでした。そのため、012は提供画像を組み込み、001から011は既存のデモ画像を維持しています。12枚を異なるファイル名またはZIPで再アップロードすれば、そのまま全画像を差し替えられます。
