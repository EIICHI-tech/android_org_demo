# Voice Climate Demo

自動車ナビ風の横画面で、タッチ操作と日本語の音声認識、音声合成を使って空調状態を変更する展示用Androidデモです。実車やCANには接続せず、画面上の状態だけを変更します。

## 開き方
1. Android Studioでこのフォルダーを開く
2. Gradle Syncを実行
3. Android 6.0以上の端末を接続してRun
4. 初回起動時にマイク権限を許可

推奨は横長タブレットまたはG510の1280x720前後の画面です。compileSdk 35、targetSdk 35、minSdk 23です。

## 音声コマンド例
- 「エアコンをつけて」「エアコンを消して」
- 「温度を24度にして」
- 「暑い」「温度を1度下げて」「暖かくして」
- 「風量を上げて」「風量を最大にして」「風を弱くして」
- 「オートにして」「内気循環にして」「外気導入にして」
- 「左右の温度を同期して」
- 「フロントガラスの曇りを取って」
- 複合例「温度を24度にして、風量を上げて」

## 注意
Android標準SpeechRecognizerは端末に認識サービスが必要です。認識方式によってネットワークを使用します。TextToSpeechの日本語音声データが端末にない場合は、端末設定から日本語音声を導入してください。
