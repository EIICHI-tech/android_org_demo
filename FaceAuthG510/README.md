# FaceAuthG510

G510向けAndroid顔認証デモPoCです。

## 機能
- 前面カメラのプレビュー
- ML Kitによる顔検出
- 1名だけ映っていることを確認
- 顔領域から32x32正規化特徴量を生成して端末内登録
- コサイン類似度による本人照合
- 一致度表示、登録消去
- ML Kit bundledモデルを使用するため、実行時のモデルダウンロードは不要

## ビルド
Android Studioでこのフォルダーを開き、Gradle Sync後にappを実行します。初回Gradle Syncには依存ライブラリ取得のためインターネット接続が必要です。

## G510への導入
`adb install -r app/build/outputs/apk/debug/app-debug.apk`

## 注意
これは顔検出を土台にした展示用の簡易顔照合です。照明、角度、表情、カメラ差に影響されます。なりすまし防止、生体検知、暗号鍵管理、FAR/FRR評価は含みません。決済、入退室、機密情報アクセスの単独認証には使用しないでください。
