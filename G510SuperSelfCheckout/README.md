# G510 スーパーセルフレジ デモ

## 機能
- 食品 / 飲料 / 青果 / 日用品の4カテゴリ
- 商品カードから登録
- バーコード番号入力と読取デモ（空欄なら食パン 4901001）
- カート、数量、小計、デモ消費税、合計
- 支払い方法選択と会計完了
- 横画面固定、ネット接続不要

## 注意
本アプリはUI PoCです。実決済、実バーコードカメラ読取、重量センサー連携、レシート印刷は未実装です。

## APK生成
Android Studioで本フォルダーを開き、Build > Build APK(s)。
生成先: app/build/outputs/apk/debug/app-debug.apk

## G510へインストール
adb install -r app-debug.apk
